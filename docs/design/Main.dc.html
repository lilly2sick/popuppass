04 / BASE TEMPLATE

  1. Background, every screen. Black ground, light grid, iridescent shimmer on the grid lines, two slow color glows.
  2. Event bar. A mini lanyard badge: event, Live / Day N, booth, today's net, Offline / Synced. Tap opens Events.
  3. Page header. Title left, one primary action right, same spot on every tab.
  4. Content. Shared cards only. Tiles fill their box; no empty squares.
  5. Tab bar + PUP. Home, Shop, Sell, Create, Insights. PUP floats bottom-right for FAQs.
